# ART_PALACE

A simple React app for showcasing artwork, artist profiles, and gallery experiences with an Appwrite backend.

## Features
- Browse artwork and gallery collections
- View artist and artwork details
- User-friendly React frontend
- Appwrite-powered backend for data and authentication

## Tech Stack
- React
- JavaScript
- Appwrite
- CSS

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shoaib-khan-24/ART_PALACE.git
   ```
2. Navigate into the project folder:
   ```bash
   cd ART_PALACE
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
